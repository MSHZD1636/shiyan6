# 实验七 · 个人简历数据可视化

将《梅晠辉个人简历》转化为体现**数据可视化**的 HTML / H5 版本。

## 文件
- `index.html` —— 数据可视化版简历（单文件，纯 HTML + CSS + 内联 SVG，无外部依赖，可离线打开）。

## 数据可视化亮点
| 可视化形式 | 对应简历内容 |
|---|---|
| KPI 数据卡 | GPA 4.17、专业排名第 2、2 项科研、最高分 97 |
| 横向条形图 | 7 门主修课程成绩对比 |
| 雷达图（SVG） | 编程 / 深度学习 / 算法 / 计算机视觉 / 工具 / 英语 六维能力 |
| 环形进度图 | 英语四级 515、六级 477 |
| 时间轴 | 国家级 + 省级两项科研项目 |

## 易企秀（eqxiu）嵌入说明（对应实验步骤）
推荐**方案 1：自定义代码组件**
1. 电脑浏览器登录 eqxiu.com → 创建作品 → 选 **H5 长页** → 新建空白长页。
2. 拖入「自定义代码」组件铺满全屏，双击打开编辑框。
3. **CSS 标签**：粘贴 `index.html` 中 `<style>…</style>` 之间的全部样式。
4. **HTML 标签**：粘贴 `<body>…</body>` 之间的全部内容。
5. **JS 标签留空** → 确定保存 → 预览 → 发布，生成可转发的 H5 链接。

> 发布后获得 H5 链接，可生成二维码放置于个人形象照上方，扫码即可查看本简历。
